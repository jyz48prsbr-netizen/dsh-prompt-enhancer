# 增强提示词按钮（prompt-enhancer）

在输入框**模型选择器左侧**增加「✦ 增强提示词」按钮。点击把当前草稿改写为更清晰具体的提示词并写回；支持一键恢复原文、取消、内容漂移保护。

## 提示词（原版，逐字未改）

系统提示词 `Ur`（2986 字符）与用户模板 `Wr`（3010 字符）**逐字取自** WorkBuddy 5.11.3 的 `server.js`，含原始缩进、引号与全部中英文示例，一字未动。处理规则同样原样保留：`{input}` 替换、`stripWrappingQuotes` 去首尾引号、空结果判定。

## 其余部分（整合优化，对齐 WorkBuddy 行为）

参考两个成熟的 DSH 开源实现整合：

- [sun04222/dsh-prompt-enhance](https://github.com/sun04222/dsh-prompt-enhance)（MIT）
- [2861292267/dsh-prompt-forge](https://github.com/2861292267/dsh-prompt-forge)（MIT）

整合内容：

- **Host 架构**：`inject=[]` + 惰性取服务，避免服务未就绪导致插件永久挂起；通过 `webServer.register` 挂载同源路由，并有延迟挂载兜底
- **按钮位置**：`conversation.input.right`（渲染在模型选择器之前），对应 WorkBuddy 输入框布局
- **交互状态机**：空闲 → 增强中（可点取消）→ 已增强（显示「恢复原文」）→ 错误（可重试）
- **内容漂移保护**：增强期间若你继续输入，结果自动丢弃，绝不覆盖新内容
- **恢复原文**：仅在草稿仍是增强结果时可用；手动改动后自动失效
- **写入兜底**：写入失败时把结果复制到剪贴板
- **模型**：优先插件配置的 `provider`/`model`，否则跟随会话默认模型

## 说明

- 每次点击消耗一次模型请求额度。
- 原版提示词面向通用任务；个别通用模型可能在结果里带出额外文字，已加防御性清理（去外层代码块/标签行），不改动提示词本身。
